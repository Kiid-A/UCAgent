# SimpleCounter 模块规格说明

## 概述

SimpleCounter 是一个 8 位可控计数器，支持使能、清零和溢出检测。

## 接口信号

| 信号名 | 方向 | 宽度 | 说明 |
|--------|------|------|------|
| clk | 输入 | 1 | 系统时钟 |
| rst_n | 输入 | 1 | 异步复位，低电平有效 |
| enable | 输入 | 1 | 计数使能 |
| clear | 输入 | 1 | 同步清零 |
| count | 输出 | 8 | 当前计数值 |
| overflow | 输出 | 1 | 溢出标志 |

## 功能描述

1. **复位**: rst_n 低电平时，count 清零，overflow 清零
2. **清零**: clear 为高时，count 清零，overflow 清零
3. **计数**: enable 为高时，count 每周期加 1
4. **溢出**: count 到达 0xFF 后回绕到 0x00，同时 overflow 拉高一个周期

## 验证目标

1. **复位功能**: 验证复位后所有信号回到初始状态
2. **使能控制**: 验证 enable=0 时计数不增加
3. **计数递增**: 验证 enable=1 时每周期加 1
4. **清零功能**: 验证 clear 信号的同步清零行为
5. **溢出检测**: 验证 0xFF→0x00 的回绕和 overflow 标志
